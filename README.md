# Spotify User Behavior Analysis

A small Python data analysis project using Pandas and Matplotlib to analyze Spotify user behavior.

## What it does

The program analyzes Spotify users who currently use the free version of Spotify and looks if they are willing to buy the premium version after a certian time period and how that changes over time.

It groups the results by how long users have been using Spotify:
- More than 2 years
- 1 year to 2 years
- 6 months to 1 year
- Less than 6 months

For each group, it calculates:
- Number of users willing to buy Premium
- Number of users not willing to buy Premium
- Percentage willing to buy Premium
- Percentage not willing to buy Premium

## Technologies

- Python
- Pandas
- Matplotlib
- Excel data

## How to run
Installing pandas, matplotlib and openpyxl using pip is essential.

## Output

The program prints a Pandas DataFrame and bar charts using Matplotlib.

## Purpose

This project was created to practice data filtering, DataFrames, categorical data, loops, and basic statistical analysis with Python, Pandas and a new addition Matplotlib.
